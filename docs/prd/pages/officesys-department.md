## 1. 页面概述

### 1.1 页面目的

提供系统部门的管理功能，包括部门列表查看、新增部门、编辑部门信息、删除部门等操作。系统管理员可通过此页面对企业组织架构进行维护。

### 1.2 访问角色

| 角色 | 权限 |
|------|------|
| 系统管理员 | 增删改查全部部门 |
| 其他角色 | 无访问权限 |

### 1.3 入口

- 左侧菜单：系统管理 > 部门管理
- 仅系统管理员可见此菜单项

## 3. 功能流程

### 3.1 部门列表查询流程

```
1. 页面加载 → 自动请求部门列表
2. 调用API: GET /api/departments
3. 返回数据 → 渲染表格
4. 用户输入筛选条件 → 点击查询
5. 前端过滤 → 更新表格
6. 点击重置 → 清空表单 → 重新加载全部数据
```

### 3.2 新增部门流程

```
1. 点击"新增部门"按钮
2. 弹出新增对话框
3. 填写表单：部门名称、部门描述
4. 点击确定 → 调用API: POST /api/departments
5. 成功 → 关闭对话框 → 刷新列表 → 提示成功
```

### 3.3 编辑部门流程

```
1. 点击表格"编辑"按钮
2. 弹出编辑对话框（数据回填）
3. 修改表单信息
4. 点击确定 → 调用API: PUT /api/departments/{id}
5. 成功 → 关闭对话框 → 刷新列表 → 提示成功
```

### 3.4 删除部门流程

```
1. 点击"删除"按钮
2. 弹出确认对话框
3. 点击确定 → 调用API: DELETE /api/departments/{id}
4. 成功 → 刷新列表 → 提示成功
```

### 4.1 筛选区域

| 元素名称 | 类型 | 说明 |
|----------|------|------|
| 部门名称输入框 | Input | 按部门名称模糊搜索 |
| 状态下拉框 | Select | 全部/正常/禁用 |
| 查询按钮 | Primary Button | 触发筛选 |
| 重置按钮 | Default Button | 清空所有筛选条件 |

### 4.2 操作按钮区

| 元素名称 | 类型 | 说明 |
|----------|------|------|
| 新增部门按钮 | Primary Button | 打开新增对话框 |

### 4.3 数据表格

| 元素名称 | 类型 | 宽度 | 说明 |
|----------|------|------|------|
| 部门ID | Text | 100px | 部门ID |
| 部门名称 | Text | 150px | 部门名称 |

### 4.4 新增/编辑对话框

| 元素名称 | 类型 | 说明 |
|----------|------|------|
| 弹窗标题 | Text | "新增部门" 或 "编辑部门" |

| 状态值 | 显示文本 | 标签颜色 |
|--------|----------|----------|
| 1 | 正常 | success(绿色) |

## 5. 数据需求

### 5.1 API接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/departments | GET | 获取部门列表 |
| /api/departments | POST | 创建部门 |
| /api/departments/{id} | PUT | 更新部门信息 |
| /api/departments/{id} | DELETE | 删除部门 |

### 5.2 部门数据结构

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 部门ID |
| name | String | 部门名称 |
| description | String | 部门描述 |
| status | Integer | 状态：1=正常，0=禁用 |
| createTime | String | 创建时间 |
