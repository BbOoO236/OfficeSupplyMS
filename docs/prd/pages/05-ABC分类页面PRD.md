## 3. 功能流程

### 3.1 分类结果展示流程

1. 用户进入ABC分类页面
2. 系统自动调用接口获取分类结果
3. 系统渲染图表（默认显示）
4. 系统加载物资明细列表（按消耗金额降序）

### 3.2 手动计算流程

1. 用户点击"开始计算"按钮
2. 系统调用接口重新计算ABC分类
3. 系统显示计算完成提示
4. 系统更新图表和数据列表

### 3.3 筛选流程

1. 用户输入物资名称筛选
2. 用户输入物资编码筛选
3. 用户选择ABC分类筛选
4. 点击"筛选"按钮应用条件
5. 点击"重置"按钮清空条件

## 6. 数据字段说明

### 6.1 ABC分类计算规则

```
1. 计算每种物资年消耗金额 = 单价 × 年消耗量
2. 按消耗金额降序排列
3. 计算累计金额和累计百分比
4. 分类标准：
   - A类：累计占比前70%（重点管理）
   - B类：累计占比70%-90%（中等管理）
   - C类：累计占比90%-100%（简单管理）
```

### 6.2 返回数据结构

| 字段 | 类型 | 说明 |
|------|------|------|
| materialName | String | 物资名称 |
| materialCode | String | 物资编码 |
| consumptionAmount | BigDecimal | 年消耗金额 |
| cumulativePercentage | BigDecimal | 累计百分比 |
| abcClass | String | 分类标签：A/B/C |
| managementStrategy | String | 管理策略说明 |

## 7. API接口

### 7.1 获取ABC分类结果

```
GET /api/algorithms/abc-classification
响应: Result<List<AbcClassificationVO>>
```

### 7.2 批量计算

```
POST /api/algorithms/schedule/abc-classification
响应: Result<Void>
```

说明：批量计算任务由系统后台执行，前端通过"刷新数据"按钮获取最新计算结果。
