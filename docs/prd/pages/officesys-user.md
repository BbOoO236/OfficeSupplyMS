## 1. 页面概述

### 1.1 页面目的

提供系统用户的管理功能，包括用户列表查看，新增用户、编辑用户信息、启用/禁用账号、重置密码等操作。系统管理员可通过此页面对所有用户进行统一管理。

### 1.2 访问角色

| 角色 | 权限 |
|------|------|
| 系统管理员 | 增删改查全部用户、重置密码 |
| 其他角色 | 无访问权限 |

### 1.3 入口

- 左侧菜单：系统管理 > 用户管理
- 仅系统管理员可见此菜单项

## 3. 功能流程

### 3.1 用户列表查询流程

```
1. 页面加载 → 自动请求用户列表
2. 用户输入筛选条件 → 点击查询
3. 返回数据 → 更新表格
4. 点击重置 → 清空表单 → 重新加载全部数据
```

### 3.2 新增用户流程

```
1. 点击"新增用户"按钮
2. 跳转至新增用户页面 /users/add
3. 填写表单信息
4. 点击确定 → 创建用户
5. 成功 → 跳转回用户列表 → 提示成功
```

### 3.3 编辑用户流程

```
1. 点击表格"编辑"按钮
2. 跳转至编辑用户页面 /users/edit/{id}
3. 修改表单信息
4. 点击确定 → 更新用户信息
5. 成功 → 跳转回用户列表 → 提示成功
```

### 3.4 禁用/启用用户流程

```
1. 点击"禁用"按钮
2. 弹出确认对话框
3. 点击确定 → 更新用户状态
4. 成功 → 更新列表状态 → 按钮变为"启用" → 提示成功
```

### 3.5 重置密码流程

```
1. 点击"重置密码"按钮
2. 弹出重置密码对话框
3. 输入新密码和确认密码
4. 点击确定 → 调用重置密码接口
5. 成功 → 提示"重置密码成功"
```

## 4. 界面元素清单

### 4.1 筛选区域

| 元素名称 | 类型 | 说明 |
|----------|------|------|
| 用户名输入框 | Input | 按用户名模糊搜索 |
| 真实姓名输入框 | Input | 按真实姓名模糊搜索 |
| 角色下拉框 | Select | 全部/普通用户/管理员 |
| 部门输入框 | Input | 按部门名称模糊搜索 |
| 状态下拉框 | Select | 全部/正常/禁用 |
| 查询按钮 | Primary Button | 触发筛选 |
| 重置按钮 | Default Button | 清空所有筛选条件 |

### 4.2 操作按钮区

| 元素名称 | 类型 | 说明 |
|----------|------|------|
| 新增用户按钮 | Primary Button | 跳转至新增用户页面 |
| 批量重置密码按钮 | Warning Button | 打开重置密码对话框 |

### 4.3 数据表格

| 元素名称 | 类型 | 宽度 | 说明 |
|----------|------|------|------|
| 用户名 | Text | 120px | 用户登录名 |
| 真实姓名 | Text | 120px | 用户真实姓名 |
| 角色 | Tag | 100px | 管理员(红色)/员工(默认) |
| 部门 | Text | 120px | 所属部门名称 |
| 邮箱 | Text | 180px | 邮箱地址 |
| 电话 | Text | 120px | 联系电话 |
| 状态 | Tag | 100px | 正常(绿色)/禁用(灰色) |
| 创建时间 | Text | 160px | 格式：YYYY-MM-DD HH:mm |
| 操作 | Button Group | 240px | 编辑/禁用或启用/重置密码 |

### 4.4 重置密码对话框

| 元素名称 | 类型 | 说明 |
|----------|------|------|
| 弹窗标题 | Text | "重置密码 - {用户名}" |
| 新密码输入框 | Password Input | 必填，最少6位 |
| 确认密码输入框 | Password Input | 必填，需与新密码一致 |
| 确认按钮 | Primary Button | 提交重置 |
| 取消按钮 | Default Button | 关闭弹窗 |

### 4.5 角色选项

| 角色值 | 显示文本 | 标签颜色 |
|--------|----------|----------|
| admin | 管理员 | danger(红色) |
| employee | 员工 | 默认(灰色) |

### 4.6 状态选项

| 状态值 | 显示文本 | 标签颜色 |
|--------|----------|----------|
| 1 | 正常 | success(绿色) |
| 0 | 禁用 | info(灰色) |

## 5. 数据需求

### 5.1 API接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/users | GET | 获取用户列表，支持分页和筛选 |
| /api/users/{id} | GET | 获取用户详情 |
| /api/users | POST | 创建用户 |
| /api/users/{id} | PUT | 更新用户信息 |
| /api/users/{id}/status | PUT | 更新用户状态 |
| /api/users/{id}/reset-password | PUT | 重置用户密码 |
| /api/users/change-password | PUT | 修改当前用户密码 |
| /api/users/{id} | DELETE | 删除用户 |

### 5.2 用户数据结构

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 用户ID |
| username | String | 用户名 |
| realName | String | 真实姓名 |
| role | String | 角色：admin/employee |
| department | String | 部门名称 |
| email | String | 邮箱 |
| phone | String | 电话 |
| status | Integer | 状态：1=正常，0=禁用 |
| createTime | String | 创建时间 |
