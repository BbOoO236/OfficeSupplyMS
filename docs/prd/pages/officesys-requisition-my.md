## 1. 页面概述

### 1.1 功能定位

我的申领页面是普通员工的申领入口页面，提供发起申领和查看历史记录两大功能。

### 1.2 页面结构

```
+------------------------------------------------------------------+
|  顶部导航栏（Logo、系统名称、当前用户信息、退出按钮）              |
+------------------------------------------------------------------+
|  左侧菜单（256px固定宽度）  |  主内容区                           |
|  - 首页/仪表盘            |  +--------------------------------+ |
|  - 物资管理              |  |  功能卡片区域                   | |
|    - 物资列表            |  |  +------------+ +------------+   | |
|    - 库存明细            |  |  | 发起申领   | | 查看我的   |   | |
|  - 申领管理              |  |  | [图标]    | | 申领记录  |   | |
|    - 我的申领（当前页）   |  |  |           | | [图标]    |   | |
|    - 创建申领单          |  |  +------------+ +------------+   | |
|  - 数据看板              |  +--------------------------------+ |
|  - 基础管理              |                                      |
|  - 系统管理              |                                      |
+------------------------------------------------------------------+
```

## 2. 功能需求

### 2.1 功能卡片区域

| 卡片 | 功能 | 说明 |
|------|------|------|
| 发起申领 | 跳转至申领单创建页 | 点击进入创建申领表单 |
| 查看我的申领记录 | 跳转至申领记录列表 | 查看历史申领记录及审批状态 |

### 2.2 申领记录列表（子页面）

```
+------------------------------------------------------------------+
|  面包屑：我的申领 > 申领记录               |                      |
+------------------------------------------------------------------+
|  筛选区域                                  |                      |
|  申领单号[输入] 物资名称[输入]             |                      |
|  状态[下拉] 日期范围[选择]                 |                      |
|  [查询] [重置]                            |                      |
+------------------------------------------------------------------+
|  操作区：[刷新] [返回]                     |                      |
+------------------------------------------------------------------+
|  申领记录表格                              |                      |
|  申领单号 | 物资名称 | 数量 | 时间 | 状态 | 操作                   |
|  APPxxx  | 物资A    | 10   | ...  | 待审 | [查看]                  |
|  APPxxx  | 物资B    | 5    | ...  | 已拒 | [查看]                  |
+------------------------------------------------------------------+
```

#### 2.2.1 筛选区域

| 字段 | 类型 | 说明 |
|------|------|------|
| 申领单号 | 输入框 | 按申领单号模糊搜索 |
| 物资名称 | 输入框 | 按物资名称模糊搜索 |
| 状态 | 下拉选择 | 全部/待审批/已拒绝/待出库/已出库/已撤销 |
| 申领时间 | 日期范围选择器 | 筛选日期范围内的记录 |

#### 2.2.2 操作区域

| 字段 | 类型 | 说明 |
|------|------|------|
| 刷新按钮 | 成功按钮 | 刷新列表数据 |
| 返回按钮 | 默认按钮 | 返回我的申领首页 |

#### 2.2.3 申领记录表格

| 字段 | 类型 | 说明 |
|------|------|------|
| 申领单号 | 表格列 | 申领单号 |
| 物资名称 | 表格列 | 物资名称 |
| 申领数量 | 表格列 | 申领数量 |
| 申领时间 | 表格列 | 申请时间 |
| 状态 | 表格列 | 状态标签 |
| 审批意见 | 表格列 | 审批人填写的意见 |
| 操作 | 表格列 | 查看/编辑/撤销按钮 |

#### 2.2.4 状态标签

| 状态值 | 显示文本 | 标签颜色 |
|--------|----------|----------|
| PENDING | 待审批 | warning(橙色) |
| REJECTED | 已拒绝 | danger(红色) |
| TO_BE_OUTBOUND | 待出库 | info(灰色) |
| OUTBOUND | 已出库 | success(绿色) |
| CANCELLED | 已撤销 | info(灰色) |

#### 2.2.5 操作按钮

| 按钮 | 显示条件 | 说明 |
|------|----------|------|
| 查看 | 始终显示 | 查看申领详情 |
| 编辑 | 仅PENDING状态 | 编辑申领单 |
| 撤销 | 仅PENDING状态 | 撤销申领单（按钮文字为"撤销"） |

## 3. 数据需求

### 3.1 API接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/applications/my | GET | 获取当前用户的申领记录列表 |
| /api/applications/{id} | GET | 获取申领单详情 |
| /api/applications/{id} | PUT | 更新申领单（编辑） |
| /api/applications/{id}/cancel | PUT | 撤销申领单 |

### 3.2 请求参数

| 参数 | 类型 | 说明 |
|------|------|------|
| applicationNo | string | 申领单号筛选 |
| materialName | string | 物资名称筛选 |
| status | string | 状态筛选 |
| startTime | string | 开始时间 |
| endTime | string | 结束时间 |
| page | int | 页码 |
| limit | int | 每页条数 |

## 4. 交互流程

### 4.1 发起申领流程

```
用户点击"发起申领"卡片
    ↓
跳转至创建申领页 /applications/create
    ↓
用户选择物资、填写用途、紧急程度、期望时间
    ↓
提交申领
    ↓
跳转回申领记录页面
```

### 4.2 查看申领记录流程

```
用户点击"查看我的申领记录"卡片
    ↓
跳转至申领记录列表页 /applications/records
    ↓
显示当前用户的全部申领记录
    ↓
可按状态、单号、物资名称筛选
    ↓
点击"查看"进入详情页
```

### 4.3 编辑申领流程

```
用户在申领记录列表点击"编辑"按钮
    ↓
跳转至编辑模式详情页
    ↓
修改物资、数量、用途等信息
    ↓
保存更新
    ↓
返回列表页
```

### 4.4 撤销申领流程

```
用户在申领记录列表点击"撤销"按钮
    ↓
弹出确认对话框
    ↓
确认后撤销该申领单
    ↓
刷新列表
```

## 5. 异常处理

| 场景 | 处理方式 |
|------|----------|
| 列表加载失败 | 显示错误提示 |
| 无申领记录 | 显示空状态插画 + "暂无申领记录" |
