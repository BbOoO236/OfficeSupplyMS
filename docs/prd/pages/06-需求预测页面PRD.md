## 1. 页面概述

| 项目 | 内容 |
|------|------|
| 页面名称 | 需求预测 |
| 访问角色 | 库管人员、系统管理员 |
| 页面功能 | 基于历史消耗数据预测未来需求，辅助采购决策 |
| 核心价值 | 预测物资未来消耗量，指导采购计划制定 |

## 3. 功能流程

### 3.1 需求预测流程

1. 用户进入需求预测页面
2. 用户选择预测周期（1/3/6/12个月）
3. 用户选择物资（可选，不选则预测所有物资）
4. 用户点击"开始预测"按钮
5. 系统调用接口获取预测数据
6. 系统渲染图表
7. 系统加载数据表格

### 3.2 图表展示逻辑

1. 选择单个物资：显示折线图（历史消耗 + 预测值）
2. 未选择物资（预测所有）：显示柱状图对比

## 5. 交互细节

### 5.1 图表交互

| 交互 | 行为 |
|------|------|
| 鼠标悬停 | 显示具体数值 |
| 选择单物资 | 显示折线图 |
| 选择多物资 | 显示柱状图对比 |

### 5.2 预测计算

| 字段 | 计算方式 |
|------|----------|
| 历史平均月消耗 | 简单移动平均值 |
| 预测月消耗 | 加权移动平均值或简单移动平均值 |
| 预测总需求 | 预测月消耗 × 周期 |
| 建议采购量 | 向上取整(预测月消耗 × 周期) |

## 6. 数据字段说明

### 6.1 请求参数

| 参数 | 类型 | 说明 |
|------|------|------|
| period | int | 预测周期（月数） |
| materialId | Long | 物资ID（可选） |

### 6.2 返回数据结构

| 字段 | 类型 | 说明 |
|------|------|------|
| materialName | String | 物资名称 |
| materialCode | String | 物资编码 |
| historicalAvg | BigDecimal | 历史平均月消耗 |
| forecastAvg | BigDecimal | 预测月消耗 |
| forecastTotal | BigDecimal | 预测总需求 |
| confidenceInterval | String | 置信区间 |
| recommendedPurchase | Integer | 建议采购量 |

### 6.3 单物资详情返回

| 字段 | 类型 | 说明 |
|------|------|------|
| materialName | String | 物资名称 |
| materialCode | String | 物资编码 |
| simpleMovingAverage | BigDecimal | 简单移动平均 |
| weightedMovingAverage | BigDecimal | 加权移动平均 |
| historicalData | List | 历史消耗数据列表 |

## 7. API接口

### 7.1 获取需求预测列表

```
GET /api/algorithms/demand-forecast?period={period}
响应: Result<List<DemandForecastVO>>
```

### 7.2 获取单个物资需求预测

```
GET /api/algorithms/demand-forecast/{materialId}?period={period}
响应: Result<DemandForecastResult>
```

### 7.3 批量计算

```
POST /api/algorithms/schedule/demand-forecast
响应: Result<Void>
```

说明：批量计算任务由系统后台执行。
