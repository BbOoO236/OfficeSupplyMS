## 3. 功能流程

### 3.1 盘点记录列表流程

1. 库管进入库存盘点页面
2. 系统加载所有物资的盘点汇总记录
3. 库管可按物资名称、状态筛选
4. 每条记录显示：账面数量、实际数量、差异数量、状态

### 3.2 新建盘点流程

1. 库管点击「新建盘点」按钮
2. 系统弹出新建盘点弹窗
3. 库管选择物资（自动带出当前库存作为账面数量）
4. 库管输入实际盘点数量
5. 系统自动计算差异数量
6. 库管填写备注
7. 库管点击「确认」按钮
8. 系统保存盘点记录

### 3.3 调整差异流程

1. 库管点击「调整差异」按钮
2. 系统弹出调整差异弹窗（物资不可更改）
3. 库管输入实际数量
4. 库管输入调整备注（必填）
5. 库管点击「确认」按钮
6. 系统调用调整库存接口
7. 系统更新物资库存数量

### 3.4 查看详情流程

1. 库管点击「查看详情」按钮
2. 系统弹出详情对话框
3. 显示该物资的最新盘点信息
4. 显示历史盘点记录列表

## 4. 界面元素清单

### 4.1 顶部筛选区

| 元素 | 类型 | 说明 |
|------|------|------|
| 物资名称输入框 | Input | 按物资名称模糊搜索 |
| 状态下拉框 | Select | 全部/正常(NORMAL)/未调整(UNADJUSTED)/已调整(ADJUSTED) |
| 查询按钮 | Primary Button | 触发筛选 |
| 重置按钮 | Default Button | 清空筛选条件 |

### 4.2 操作按钮区

| 元素 | 类型 | 说明 |
|------|------|------|
| 新建盘点按钮 | Primary Button | 打开新建盘点弹窗 |
| 刷新按钮 | Success Button | 刷新列表 |

### 4.3 盘点记录表格

| 元素 | 类型 | 说明 |
|------|------|------|
| 物资编码 | Table Column | 物资编码 |
| 物资名称 | Table Column | 物资名称 |
| 账面数量 | Table Column | 系统当前库存数量 |
| 实际数量 | Table Column | 盘点时输入的实际数量 |
| 差异数量 | Table Column | 差异值，正数显示绿色(+x)，负数显示红色(x) |
| 盘点时间 | Table Column | 最近一次盘点时间 |
| 状态 | Table Column Tag | 正常(绿)/未调整(红)/已调整(橙) |
| 操作 | Table Column | 查看详情/调整差异按钮 |
| 分页组件 | Pagination | 默认每页20条 |

### 4.4 盘点状态说明

| 状态值 | 显示文本 | 颜色 | 条件 |
|--------|----------|------|------|
| 正常 | 正常 | success(绿色) | 差异=0 |
| 未调整 | 未调整 | danger(红色) | 差异≠0且未调整 |
| 已调整 | 已调整 | warning(橙色) | 差异≠0且已调整 |

### 4.5 新建/调整盘点弹窗

| 元素 | 类型 | 说明 |
|------|------|------|
| 弹窗标题 | Text | "新建盘点" 或 "调整差异" |
| 物资选择 | SearchableSelect | 搜索框+下拉列表，调整模式下禁用 |
| 账面数量 | Disabled Input | 显示当前库存，不可编辑 |
| 实际数量 | NumberInput | 数字输入框，最小值为0 |
| 差异数量 | Disabled Input | 自动计算（实际-账面）+ 盘盈/盘亏/无差异标签 |
| 调整备注 | Textarea | 调整时必填，新建时可选 |
| 备注 | Textarea | 新建盘点时的备注 |
| 确认按钮 | Primary Button | 提交表单 |
| 取消按钮 | Default Button | 关闭弹窗 |

### 4.6 盘点详情弹窗

| 元素 | 类型 | 说明 |
|------|------|------|
| 最新盘点信息 | Descriptions | 物资编码、名称、账面数量、实际数量、差异数量、状态、时间、备注 |
| 历史盘点记录 | Table | 盘点单号、账面数量、实际数量、差异数量、时间、状态、备注 |

## 5. 交互细节

### 5.1 新建盘点交互

| 交互 | 行为 |
|------|------|
| 选择物资 | 自动带出账面数量（当前库存） |
| 输入实际数量 | 实时计算并显示差异数量 |
| 差异标签 | 根据差异显示"盘盈"(绿)/"盘亏"(红)/"无差异"(绿) |
| 确认提交 | 保存盘点记录 |

### 5.2 调整差异交互

| 交互 | 行为 |
|------|------|
| 点击调整差异 | 打开弹窗，物资不可更改 |
| 差异标签 | 实时显示盘盈/盘亏状态 |
| 调整备注 | 必填项，不填时提示"请输入调整备注" |
| 确认提交 | 调用adjustStockByCheck更新库存 |

### 5.3 查看详情交互

| 交互 | 行为 |
|------|------|
| 点击查看详情 | 显示该物资最新盘点信息和历史记录 |
| 历史记录表格 | 按时间倒序显示所有盘点记录 |

## 8. 后置条件

1. 新建盘点后生成盘点记录
2. 调整差异后更新物资当前库存（current_stock）
3. 盘点记录永久保存
4. 库存调整后，相关页面同步刷新

## 9. API接口

### 9.1 获取盘点汇总列表

```
GET /api/inventory-checks/materials
响应: Result<List<MaterialCheckSummaryVO>>
```

### 9.2 获取物资盘点详情

```
GET /api/inventory-checks/material/{materialId}
响应: Result<MaterialCheckSummaryVO>
```

### 9.3 新建盘点

```
POST /api/inventory-checks
请求体: { materialId, actualQuantity, remark }
响应: Result<Void>
```

### 9.4 调整库存

```
POST /api/inventory-checks/adjust/{checkId}
请求体: { actualQuantity, adjustmentRemark }
响应: Result<Void>
```
