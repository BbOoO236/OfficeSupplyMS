> 创建日期：2026-04-21

## 1. 页面概述

### 1.1 功能定位

物资详情页面展示单个物资的完整档案信息，包括基础信息和算法分析结果，帮助用户了解物资的库存状况、ABC分类、补货点等关键信息，并提供快速申领入口。

### 1.2 页面结构

```
+------------------------------------------------------------------+
|  顶部导航栏（Logo、系统名称、当前用户信息、退出按钮）              |
+------------------------------------------------------------------+
|  左侧菜单（256px固定宽度）  |  主内容区                           |
|  - 首页/仪表盘            |  +--------------------------------+ |
|  - 物资管理              |  |  面包屑：物资管理 > 物资列表     | |
|    - 物资列表            |  +--------------------------------+ |
|    - 库存明细            |  |                                  | |
|  - 申领管理              |  |  +------------+  +------------+ | |
|  - 待办任务              |  |  | 物资基础信息 |  | 算法结果显示 | | |
|  - 数据看板              |  |  | 区域（左侧） |  | 区域（右侧） | | |
|  - 基础管理              |  |  +------------+  +------------+ | |
|  - 系统管理              |  |                                  | |
|                           |  |  +---------------------------+  | |

|                           |  |  +---------------------------+  | |
+------------------------------------------------------------------+
```

## 2. 功能需求

### 2.1 物资基础信息区域（左侧）

| 字段 | 说明 | 示例值 |
|------|------|--------|
| 物资编码 | 系统自动生成的唯一编码 | MAT-2024-00001 |
| 物资名称 | 物资的正式名称 | A4复印纸 |
| 物资类别 | 所属二级类别 | 办公用纸 > A4纸 |
| 规格 | 规格型号描述 | 70g/㎡，500张/包 |
| 单价 | 人民币元，含小数 | ¥25.00 |
| 单位 | 计量单位 | 包 |
| 采购提前期 | 天数 | 3天 |
| 当前库存 | 实时库存数量 | 50 |
| 状态 | 正常/库存紧张/已缺货 | 正常 |

### 2.2 算法结果显示区域（右侧）

#### 2.2.1 ABC分类标签

| 分类 | 标签颜色 | 说明 |
|------|----------|------|
| A类 | 红色背景（rgba(239, 68, 68, 0.1)），红色文字（#EF4444） | 重点管理，占年消耗金额70-80% |
| B类 | 黄色背景（rgba(245, 158, 11, 0.1)），黄色文字（#F59E0B） | 中等管理，占年消耗金额10-20% |
| C类 | 绿色背景（rgba(34, 197, 94, 0.1)），绿色文字（#22C55E） | 简单管理，占年消耗金额5-10% |

#### 2.2.2 算法指标

| 指标名称 | 计算说明 | 示例值 |
|----------|----------|--------|
| 安全库存 | 为防止需求波动设置的最低库存量 | 20 |
| 补货点 | 触发补货的库存阈值 = (日均消耗量 x 采购提前期) x 安全系数 | 45 |
| 日均消耗量 | 近30天消耗总量 / 30（排除零消耗日） | 8.5 |

### 2.3 操作按钮

| 按钮 | 样式 | 行为 |
|------|------|------|
| 立即申领 | 主按钮（蓝色背景 #0891B2） | 跳转到申领单创建页面，URL参数携带物资ID |
| 返回列表 | 次按钮（灰色边框） | 返回物资浏览页面 |

### 2.4 相关推荐区域

| 字段 | 要求 |
|------|------|
| 标题 | "同类物资推荐" |
| 内容 | 显示同二级类别下的其他物资，最多显示6个 |
| 展示形式 | 卡片列表，每张卡片显示：名称、规格、单价 |
| 点击行为 | 点击卡片进入对应物资详情页 |

## 3. 数据需求

### 3.1 页面初始化数据加载

1. 通过URL参数（/api/material/{id}）加载物资详情
2. 加载同类物资推荐列表（/api/materials/recommend?categoryId={categoryId}&excludeId={id}）

### 3.2 API接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/material/{id} | GET | 获取物资详情（含算法结果） |
| /api/materials/recommend | GET | 获取同类物资推荐，参数categoryId、excludeId |

## 4. 交互流程

### 4.1 查看详情流程

```
用户从物资列表页点击物资名称/卡片
    ↓
跳转至物资详情页 /api/material/{id}
    ↓
页面加载物资详情 + 算法结果 + 相关推荐
```

### 4.2 立即申领流程

```
用户查看物资详情 → 点击"立即申领"按钮
    ↓
跳转到申领单创建页 /api/requisition/create?materialId={id}
    ↓
申领单创建页自动带入该物资，数量默认为1
```

## 5. 异常处理

| 场景 | 处理方式 |
|------|----------|
| 物资详情加载失败 | 显示错误提示 + "返回列表"按钮 |
| 物资ID不存在 | 显示"物资不存在"提示 + "返回列表"按钮 |
| 推荐列表加载失败 | 隐藏推荐区域，不阻塞主内容显示 |
| 网络超时 | 显示Toast提示"网络异常，请重试" |

## 6. 验收标准

| 编号 | 标准描述 |
|------|----------|
| AC-1 | 物资基础信息完整显示：编码、名称、类别、规格、单价、单位、采购提前期 |
| AC-2 | 算法结果显示：ABC分类标签（颜色符合要求）、安全库存、补货点、日均消耗量 |
| AC-3 | ABC分类颜色：A类=红色、B类=黄色、C类=绿色 |
| AC-4 | 状态标签颜色：正常=绿色、库存紧张=橙色、已缺货=红色 |
| AC-5 | 点击"立即申领"按钮跳转到申领单创建页，URL携带物资ID参数 |
| AC-6 | 相关推荐显示同类别其他物资，点击可跳转 |
| AC-7 | 页面加载时显示loading状态 |
