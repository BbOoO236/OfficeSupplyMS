## 3. 功能流程

### 3.1 异常申领记录列表流程

1. 用户进入异常检测页面
2. 系统调用 `/algorithms/anomalies` 加载异常申领记录
3. 系统显示异常申领统计信息

### 3.2 申领单号查询流程

1. 用户输入申领单号
2. 点击查询按钮
3. 系统调用 `/applications/no/{applicationNo}` 获取申领单信息
4. 系统调用 `/algorithms/check-application-anomaly` 校验是否异常
5. 显示查询结果

### 3.3 异常检测规则说明

1. 用户可查看页面底部的检测规则说明
2. 说明判断条件和计算方法

### 3.4 实时异常校验

1. 用户在申领单提交时调用 `/algorithms/check-application-anomaly`
2. 系统实时计算并返回是否为异常申领
3. 审批时可看到异常标记

| 规则 | 说明 |

## 6. 数据字段说明

### 6.1 异常检测算法

```
判断条件：申领数量 > 历史平均单次申领量 + 3 × 标准差
是 → 标记为高风险申领
```

## 9. 后置条件

1. 异常申领仅作为警示，不阻塞申领流程
2. 审批人可看到异常标记，可选择通过或驳回
3. 驳回时建议填写原因（可选）
4. 高风险申领通过审批后，该记录移到历史记录

## 10. API接口

### 10.1 获取异常检测列表

```
GET /algorithms/anomaly-detection?date=yyyy-MM-dd
请求参数：
  - date (必填): 日期，格式 yyyy-MM-dd
响应: Result<List<AnomalyDetectionFlatVO>>
```

### 10.2 实时校验申领异常

```
GET /algorithms/check-application-anomaly?userId=1&materialId=1&quantity=100
响应: Result<AnomalyDetectionFlatVO>
```
