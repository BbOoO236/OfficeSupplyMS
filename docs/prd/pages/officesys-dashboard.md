## 1. 页面概述

### 1.1 页面目的

作为用户登录后的首页，展示与用户角色相关的关键数据统计、快捷入口和待办任务提醒。不同角色看到的首页内容不同：

- **系统管理员**：全公司数据统计、待审批任务、库存预警、入库/出库统计
- **普通员工**：我的申领进度、常用物资、快捷申领入口

### 1.2 访问角色

| 角色 | 显示内容 |
|------|----------|
| 系统管理员 | 全局统计数据、待审批任务、库存预警、入库/出库统计 |
| 普通员工 | 我的申领记录、快捷申领入口、物资浏览 |

### 1.3 入口

- 用户登录成功后自动跳转
- 点击顶部Logo或"首页"菜单项

## 3. 功能流程

### 3.1 页面加载流程

```
1. 用户登录成功 → 跳转首页
2. 读取localStorage中的用户信息
3. 根据用户角色请求对应数据
4. 渲染欢迎信息、统计卡片、快捷入口等
5. 数据加载完成
```

### 3.2 数据请求

```
管理员:
  GET /api/dashboard/admin
  → { userCount, materialCount, pendingApproval, pendingOutbound, warningCount, warnings[], pendingApprovalList[], pendingOutboundList[] }

普通员工:
  GET /api/dashboard/employee?userId=xxx
  → { applying, approved, rejected, received, recentApplications[], topMaterials[] }
```

### 3.3 快捷操作流程

| 操作 | 流程 |
|------|------|
| 点击统计卡片 | 跳转到对应的列表页面 |
| 点击快捷入口 | 跳转到对应功能页面 |
| 点击待办任务 | 跳转到审批/处理详情页 |
| 点击"提交申领" | 跳转到申领单创建页面 |

## 5. 交互细节

### 5.1 点击行为

| 交互元素 | 行为 | 目标页面 |
|----------|------|----------|
| 点击统计卡片 | 路由跳转 | 根据卡片类型跳转 |
| 点击快捷入口按钮 | 路由跳转 | 对应功能页面 |
| 点击待办任务项 | 路由跳转 | 任务详情页面 |
| 点击"查看更多" | 路由跳转 | 完整列表页面 |
| 点击顶部Logo | 刷新当前页 | 保持在本页 |

### 5.2 悬停行为

| 交互元素 | 悬停效果 |
|----------|----------|
| 统计卡片 | 轻微上移，阴影加深 |
| 快捷入口按钮 | 背景色加深，图标放大 |
| 待办任务项 | 背景色变浅高亮 |
| 预警列表项 | 显示"查看详情"链接 |

### 5.3 加载状态

| 场景 | 显示内容 |
|------|----------|
| 页面初始加载 | 骨架屏或loading动画 |
| 卡片数据加载中 | 卡片区域显示loading色块 |
| 数据加载失败 | 显示重试按钮 |

### 5.4 空状态

| 场景 | 显示内容 |
|------|----------|
| 无待办任务 | 显示"暂无待处理任务" + 插图 |
| 无预警信息 | 不显示预警区域 |
| 无申领记录 | 显示"您还没有申领记录" + "立即申领"按钮 |

## 7. 状态处理

### 7.1 状态定义

| 状态类型 | 状态值 | 视觉表现 |
|----------|--------|----------|
| 申领状态-待审批 | PENDING | 橙色标签 |
| 申领状态-已拒绝 | REJECTED | 红色标签 |
| 申领状态-待出库 | TO_BE_OUTBOUND | 灰色标签 |
| 申领状态-已出库 | OUTBOUND | 绿色标签 |
| 申领状态-已撤销 | CANCELLED | 灰色标签 |
| 库存状态-正常 | NORMAL | 绿色标签 |
| 库存状态-库存过低 | LOW | 红色标签 |
| 库存状态-库存过高 | HIGH | 橙色标签 |

### 7.2 异常处理

| 场景 | 处理方式 |
|------|----------|
| 数据加载失败 | 显示错误提示 + 重试按钮 |
| Token过期 | 跳转登录页 |
| 网络断开 | 显示网络异常提示 |

## 8. 非功能性需求

### 8.1 性能要求

| 指标 | 要求 |
|------|------|
| 页面首次加载 | ≤ 3秒 |
| 数据刷新 | ≤ 1秒 |
| 卡片加载顺序 | 统计卡片优先，图表延迟加载 |

### 8.2 响应式要求

| 断点 | 布局变化 |
|------|----------|
| < 768px | 侧边栏收起，统计卡片单列显示 |
| 768px - 992px | 统计卡片2列显示 |
| 992px - 1200px | 统计卡片3列显示 |
| > 1200px | 统计卡片4列显示 |
