## 3. 功能流程

### 3.1 库存列表加载流程

1. 用户进入库存明细页面
2. 系统加载统计数据（物资种类、总库存数量、低库存物资、需补货物资）
3. 系统加载物资列表（默认按物资编码升序）
4. 每条记录显示当前库存和安全库存、补货点

### 3.2 筛选流程

1. 用户可输入物资名称搜索
2. 用户可输入物资编码搜索
3. 用户可选择库存状态下拉（库存充足/库存过低/库存过高）
4. 用户可选择ABC分类下拉（A类/B类/C类）
5. 点击查询后按条件过滤

### 3.3 操作按钮流程

1. 点击"入库操作" → 跳转入库页面
2. 点击"出库操作" → 跳转出库页面
3. 点击"库存盘点" → 跳转盘点页面
4. 点击"查看低库存" → 自动筛选库存过低物资

### 3.4 操作列流程

1. 点击"入库记录" → 跳转入库页面并带上物资ID
2. 点击"出库记录" → 跳转出库页面并带上物资ID
3. 点击"盘点" → 跳转盘点页面并带上物资ID

## 4. 界面元素清单

### 4.1 顶部筛选区

| 元素 | 类型 | 说明 |
|------|------|------|
| 物资名称输入框 | Input | 按物资名称模糊搜索 |
| 物资编码输入框 | Input | 按物资编码搜索 |
| 库存状态下拉框 | Select | 全部/库存充足(NORMAL)/库存过低(LOW)/库存过高(HIGH) |
| ABC分类下拉框 | Select | 全部/A类/B类/C类 |
| 查询按钮 | Primary Button | 触发筛选 |
| 重置按钮 | Default Button | 清空筛选条件 |

### 4.2 统计卡片区

| 元素 | 类型 | 说明 |
|------|------|------|
| 物资种类卡片 | Stat Card | 显示物资种类总数 |
| 总库存数量卡片 | Stat Card | 显示所有物资库存之和 |
| 低库存物资卡片 | Stat Card | 显示库存状态为LOW的物资数量 |
| 需补货物资卡片 | Stat Card | 显示需要补货的物资数量 |

### 4.3 操作按钮区

| 元素 | 类型 | 说明 |
|------|------|------|
| 入库操作按钮 | Primary Button | 跳转至入库管理页面 |
| 出库操作按钮 | Success Button | 跳转至出库管理页面 |
| 库存盘点按钮 | Warning Button | 跳转至库存盘点页面 |
| 查看低库存按钮 | Danger Button | 自动筛选库存过低物资 |

### 4.4 数据表格

| 元素 | 类型 | 说明 |
|------|------|------|
| 物资编码 | Table Column | 物资编码 |
| 物资名称 | Table Column | 物资名称 |
| 规格 | Table Column | 规格 |
| 单位 | Table Column | 单位 |
| 当前库存 | Table Column Tag | 库存数量，LOW显示红色，HIGH显示橙色，正常显示绿色 |
| 安全库存 | Table Column | 安全库存阈值 |
| 补货点 | Table Column | 计算后的补货点 |
| 是否需要补货 | Table Column Tag | 是(红色)/否(绿色) |
| ABC分类 | Table Column Tag | A类(红色)/B类(橙色)/C类(默认) |
| 操作 | Button Group | 入库记录/出库记录/盘点 |

### 4.5 库存状态标签说明

| 状态 | 颜色 | 条件 |
|------|------|------|
| 正常/库存充足 | 绿色 | stockStatus = NORMAL |
| 库存过低 | 红色 | stockStatus = LOW |
| 库存过高 | 橙色 | stockStatus = HIGH |

## 5. 交互细节

### 5.1 筛选交互

| 交互 | 行为 |
|------|------|
| 物资名称/编码 | 输入后回车或点击查询触发搜索 |
| 状态/ABC分类筛选 | 选择后点击查询触发 |
| 查看低库存 | 自动设置stockStatus=LOW并触发筛选 |

### 5.2 分页交互

| 交互 | 行为 |
|------|------|
| 切换页码 | 重新加载当前筛选条件下的数据 |
| 切换每页条数 | 重新加载数据 |

## 8. 验收标准

| 编号 | 标准描述 |
|------|----------|
| AC-1 | 顶部显示4个统计卡片：物资种类、总库存数量、低库存物资、需补货物资 |
| AC-2 | 筛选区域支持物资名称、物资编码、库存状态、ABC分类筛选 |
| AC-3 | 操作按钮区显示4个按钮：入库操作、出库操作、库存盘点、查看低库存 |
| AC-4 | 表格显示：编码、名称、规格、单位、当前库存、安全库存、补货点、是否需要补货、ABC分类 |
| AC-5 | 当前库存标签颜色根据库存状态显示 |
| AC-6 | 操作列显示：入库记录、出库记录、盘点按钮 |
| AC-7 | 分页显示，默认每页20条 |
