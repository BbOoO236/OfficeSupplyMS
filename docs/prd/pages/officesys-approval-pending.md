> 文档版本：V1.1
> 创建日期：2026-04-21
> 更新日期：2026-04-23
> 所属模块：物资申领流程

## 1. 页面概述

### 1.1 功能定位

待批申领页面展示当前用户提交的待审批申领单列表，支持按申领单号、物资名称、状态筛选，帮助用户跟踪申领进度。

### 1.2 页面结构

```
+------------------------------------------------------------------+
|  顶部导航栏（Logo、系统名称、当前用户信息、退出按钮）              |
+------------------------------------------------------------------+
|  左侧菜单（256px固定宽度）  |  主内容区                           |
|  - 首页/仪表盘            |  +--------------------------------+ |
|  - 物资管理              |  |  面包屑：我的申领 > 待批申领     | |
|    - 物资列表            |  +--------------------------------+ |
|    - 库存明细            |  |  筛选区域                       | |
|  - 申领管理              |  |  申领单号[输入] 物资名称[输入]  | |
|    - 我的申领            |  |  状态[下拉] [查询] [重置]      | |
|    - 待批申领（当前页）   |  +--------------------------------+ |
|  - 数据看板              |  |  操作区                         | |
|  - 基础管理              |  |  [刷新]                        | |
|  - 系统管理              |  +--------------------------------+ |
|                           |  |  申领单表格                     | |
|                           |  |  申领单号 | 物资名称 | 数量 |   | |
|                           |  |  用途 | 时间 | 状态 | 审批意见 |  | |
|                           |  |  [查看]                        | |
|                           |  +--------------------------------+ |
+------------------------------------------------------------------+
```

## 2. 功能需求

### 2.1 筛选区域

| 字段 | 类型 | 说明 |
|------|------|------|
| 申领单号 | 输入框 | 按申领单号模糊搜索 |
| 物资名称 | 输入框 | 按物资名称模糊搜索 |
| 状态 | 下拉选择 | 待审批(PENDING)、待出库(TO_BE_OUTBOUND) |
| 查询按钮 | 主按钮 | 触发筛选 |
| 重置按钮 | 默认按钮 | 清空所有筛选条件 |

### 2.2 操作区域

| 字段 | 类型 | 说明 |
|------|------|------|
| 刷新按钮 | 成功按钮 | 刷新列表数据 |

### 2.3 申领单列表

| 字段 | 类型 | 说明 |
|------|------|------|
| 申领单号 | 表格列 | 申领单号 |
| 物资名称 | 表格列 | 物资名称 |
| 申领数量 | 表格列 | 数量 + 单位 |
| 用途 | 表格列 | 申领用途 |
| 申领时间 | 表格列 | 格式：YYYY-MM-DD HH:mm |
| 状态 | 表格列 | 待审批(橙色标签)、待出库(灰色标签) |
| 审批意见 | 表格列 | 审批人填写的意见 |
| 操作 | 表格列 | 仅"查看"按钮 |

### 2.4 状态说明

| 状态值 | 显示文本 | 标签颜色 |
|--------|----------|----------|
| PENDING | 待审批 | warning(橙色) |
| TO_BE_OUTBOUND | 待出库 | info(灰色) |

## 3. 数据需求

### 3.1 页面初始化数据加载

1. 加载当前用户的待审批申领单列表（默认status=PENDING）

### 3.2 API接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/applications/my | GET | 获取当前用户的申领记录，支持status参数过滤 |

### 3.3 请求参数

| 参数 | 类型 | 说明 |
|------|------|------|
| applicationNo | string | 申领单号筛选 |
| materialName | string | 物资名称筛选 |
| status | string | 状态筛选：PENDING/TO_BE_OUTBOUND |
| page | int | 页码 |
| limit | int | 每页条数 |

## 4. 交互流程

### 4.1 查看待批申领列表

```
用户进入"待批申领"页面
    ↓
页面自动加载待审批的申领单列表
    ↓
用户可按申领单号、物资名称、状态进行筛选
    ↓
用户点击"查看"按钮 → 进入申领详情页
```

### 4.2 查看申领详情

```
用户在列表页点击"查看"按钮
    ↓
跳转至申领详情页 /applications/{id}
    ↓
显示申领单完整信息及审批历史
```

## 5. 异常处理

| 场景 | 处理方式 |
|------|----------|
| 列表加载失败 | 显示错误提示 |
| 无待批申领记录 | 显示空状态插画 + "暂无待审批的申领" |

## 6. 验收标准

| 编号 | 标准描述 |
|------|----------|
| AC-1 | 页面加载时默认显示待审批(PENDING)的申领单列表 |

| AC-3 | 列表显示：申领单号、物资名称、申领数量、用途、申领时间、状态、审批意见 |
