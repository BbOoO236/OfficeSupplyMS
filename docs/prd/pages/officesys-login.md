## 1. 页面概述

### 1.1 页面目的

提供用户登录功能，用户通过输入用户名和密码登录系统。系统支持系统管理员和普通员工两种角色，不同角色登录后显示不同的导航菜单和首页内容。

### 1.2 访问角色

| 角色 | 说明 |
|------|------|
| 全部未登录用户 | 可访问登录页，输入账号密码登录 |

### 1.3 入口

- 首次访问系统：`http://localhost:3000` 或 `http://localhost:3000/login`
- 退出登录后：自动跳转至登录页

## 3. 功能流程

### 3.1 页面加载流程

```
1. 用户访问登录页
2. 页面显示左侧品牌区和右侧登录表单
3. 默认选中"系统管理员"角色
4. 用户输入用户名和密码
```

### 3.2 登录流程

```
1. 用户输入用户名
2. 用户输入密码
3. 点击"登录"按钮
4. 显示loading状态（按钮显示"登录中..."）
5. 调用登录API
6. 登录成功：
   - 存储Token到localStorage
   - 跳转到首页 /
7. 登录失败：
   - 在表单上方显示红色错误提示条
   - 按钮恢复可点击状态
```

### 3.3 登录错误类型及提示

| 错误类型 | 错误提示 | HTTP状态码 |
|----------|----------|------------|
| 用户名不存在 | 用户名或密码错误 | 401 |
| 密码错误 | 用户名或密码错误，剩余N次尝试机会 | 401 |
| 密码错误累计5次 | 密码错误次数过多，账号已锁定15分钟 | 401 |
| 账号已锁定 | 账号已锁定，请XX:XX:XX后再试 | 401 |
| 角色选择错误 | 角色权限错误，请选择正确的身份登录 | 403 |
| 用户已被禁用 | 用户已被禁用 | 403 |

### 3.4 密码错误锁定规则

- 连续密码错误5次后，账号被锁定15分钟
- 每次密码错误时，提示剩余尝试次数
- 锁定时间到达后自动解锁，无需管理员干预
- 登录成功后，错误计数重置

## 5. 交互细节

### 5.1 角色选择交互

| 交互 | 行为 |
|------|------|
| 点击角色 | 设置当前角色类型（admin/employee） |
| 默认选中 | 系统管理员 |

### 5.2 表单验证

| 字段 | 验证规则 | 错误提示 |
|------|----------|----------|
| 用户名 | 不能为空 | 请输入用户名 |
| 密码 | 不能为空 | 请输入密码 |

### 5.3 登录状态

| 场景 | 显示内容 |
|------|----------|
| 登录请求中 | 按钮显示"登录中..."，禁用点击 |
| 登录失败 | 在表单上方显示红色错误提示条，不弹系统Message框 |
| 登录失败-用户名密码错误 | 提示"用户名或密码错误，剩余N次尝试机会" |
| 登录失败-账号锁定 | 提示"密码错误次数过多，账号已锁定15分钟" |
| 登录失败-角色错误 | 提示"角色权限错误，请选择正确的身份登录" |
| 登录失败-用户禁用 | 提示"用户已被禁用" |

## 6. 数据字段

### 6.1 登录请求数据结构

```javascript
{
  username: string,  // 用户账号
  password: string   // 用户密码
}
```

### 6.2 登录响应数据结构

```javascript
{
  code: number,       // 状态码，200表示成功
  message: string,    // 消息
  data: {
    token: string,    // JWT Token
    user: {
      id: number,     // 用户ID
      username: string, // 用户名
      realName: string, // 真实姓名
      role: string,   // 角色代码：admin/employee
      roleName: string, // 角色名称
      departmentId: number, // 部门ID
      departmentName: string // 部门名称
    }
  }
}
```
