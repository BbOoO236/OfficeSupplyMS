## 1. 页面概述

### 1.1 功能定位

物资浏览页面是用户进入系统后的主要入口页面，承载物资目录展示、分类筛选、关键字搜索、ABC分类筛选、视图切换六大核心功能，帮助用户快速找到所需物资并进入申领流程。

### 1.2 页面结构

```
+------------------------------------------------------------------+
|  顶部导航栏（Logo、系统名称、当前用户信息、退出按钮）              |
+------------------------------------------------------------------+
|  左侧菜单（256px固定宽度）  |  主内容区                           |
|  - 首页/仪表盘            |  +--------------------------------+ |
|  - 物资管理              |  |  筛选区域                        | |
|    - 物资列表（当前页）   |  |  物资名称[输入] 物资编码[输入]   | |
|    - 库存明细            |  |  物资类别[下拉] ABC分类[下拉]    | |
|  - 申领管理              |  |  [查询] [重置]                   | |
|  - 待办任务              |  +--------------------------------+ |
|  - 数据看板              |  |  操作按钮区                      | |
|  - 基础管理              |  |  [新增物资] [低库存物资] [需补货] | |
|  - 系统管理              |  |                   [列表] [卡片]  | |
|                           |  +--------------------------------+ |
|                           |  |  物资表格/卡片列表               | |
|                           |  |  ...                            | |
|                           |  +--------------------------------+ |
+------------------------------------------------------------------+
```

## 2. 功能需求

### 2.1 筛选区域

| 字段 | 要求 |
|------|------|
| 物资名称 | 输入框，支持模糊搜索 |
| 物资编码 | 输入框，支持模糊搜索 |
| 物资类别 | 下拉选择，支持筛选，可清空 |
| ABC分类 | 下拉选择（仅管理员可见），选项：A类/B类/C类 |
| 查询按钮 | 主按钮，触发筛选 |
| 重置按钮 | 默认按钮，清空所有筛选条件 |

### 2.2 操作按钮区

| 字段 | 要求 |
|------|------|
| 新增物资 | 主按钮（仅管理员），点击跳转至新增物资页面 |
| 低库存物资 | 警告按钮（仅管理员），点击筛选显示低库存物资 |
| 需补货物资 | 危险按钮（仅管理员），点击筛选显示需补货物资 |
| 视图切换 | 按钮组，包含"列表"和"卡片"两个选项 |

### 2.3 物资列表

#### 2.3.1 展示形式

支持表格视图和卡片视图两种模式，默认表格视图，通过页面右上角按钮切换。

#### 2.3.2 表格视图

| 字段 | 列名 | 宽度 | 说明 |
|------|------|------|------|
| 物资编码 | code | 120px | |
| 物资名称 | name | 150px+ | 可点击跳转详情 |
| 规格 | specification | 120px | |
| 单位 | unit | 80px | |
| 单价 | unitPrice | 100px | 格式：¥xx |
| 当前库存 | currentStock | 100px | 仅管理员可见，库存状态标签 |
| 安全库存 | safetyStock | 100px | 仅管理员可见 |
| ABC分类 | abcClass | 100px | 仅管理员可见，A类(红色)/B类(橙色)/C类(默认) |
| 状态 | status | 100px | 仅管理员可见，正常(绿色)/停用(灰色) |
| 操作 | action | 200px | 管理员：编辑/停用或启用；员工：申领按钮 |

#### 2.3.3 卡片视图

| 字段 | 要求 |
|------|------|
| 布局 | 响应式网格布局，每行根据屏幕宽度自动调整 |
| 卡片内容 | 物资名称、编码、分类、规格、单价、库存（带状态标签） |
| 库存状态标签颜色 | LOW(库存过低)=danger(红色)、HIGH(库存过高)=warning(橙色)、NORMAL(正常)=success(绿色) |
| 卡片底部操作 | 管理员：编辑/申领；员工：申领物资/详情 |

### 2.4 快捷筛选功能

| 功能 | 说明 |
|------|------|
| 低库存物资 | 点击后将stockStatus设为'LOW'，筛选出所有库存过低的物资 |
| 需补货物资 | 调用API获取所有需要补货的物资，单独展示 |

### 2.5 分页

| 字段 | 要求 |
|------|------|
| 默认条数 | 每页20条 |
| 位置 | 列表底部 |
| 样式 | 显示总条数、页码导航 |

## 3. 数据需求

### 3.1 页面初始化数据加载

1. 加载物资类别选项
2. 加载物资列表第1页（默认展示全部物资）

### 3.2 API接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/materials | GET | 获取物资列表，支持分页、名称/编码/类别/ABC分类/库存状态筛选 |
| /api/materials/categories | GET | 获取物资类别列表 |
| /api/materials/need-reorder | GET | 获取需补货的物资列表 |
| /api/materials/{id} | DELETE | 停用物资 |
| /api/materials/{id}/status | PUT | 更新物资状态（启用/停用） |

## 4. 交互流程

### 4.1 浏览流程

```
用户进入页面 → 加载类别树 + 物资列表（第1页）
    ↓
用户点击类别树节点 → 右侧列表筛选该类别物资
    ↓
用户输入关键字搜索 → 回车触发搜索 → 显示搜索结果
    ↓
用户点击"全部收起"→ 类别树收起 → 显示全量物资
```

### 4.2 进入详情流程

```
用户浏览物资列表 → 点击物资名称/卡片
    ↓
跳转至物资详情页 /api/material/{id}
```

## 5. 异常处理

| 场景 | 处理方式 |
|------|----------|
| 类别树加载失败 | 显示错误提示，点击重试按钮重新加载 |
| 物资列表加载失败 | 显示错误提示，点击重试按钮重新加载 |
| 搜索无结果 | 显示空状态插画 + "未找到相关物资"文字 |
| 网络超时 | 显示Toast提示"网络异常，请重试" |

## 6. 验收标准

| 编号 | 标准描述 |
|------|----------|
| AC-1 | 物资名称和编码支持模糊搜索筛选 |
| AC-2 | 物资类别和ABC分类支持下拉筛选 |
| AC-3 | ABC分类筛选仅对管理员可见 |
| AC-4 | 物资列表默认显示20条/页，支持分页切换 |
| AC-5 | 物资卡片/表格显示：名称、编码、规格、单价、库存数（带状态标签） |
| AC-6 | 库存状态标签颜色：LOW(库存过低)=红色、HIGH(库存过高)=橙色、NORMAL(正常)=绿色 |
| AC-7 | 点击物资名称或卡片可进入物资详情页 |
| AC-8 | 支持卡片视图和表格视图切换 |
| AC-9 | "低库存物资"按钮筛选显示所有库存过低的物资 |
| AC-10 | "需补货物资"按钮获取并显示所有需要补货的物资 |
| AC-11 | 管理员可对物资进行编辑、停用/启用操作 |
| AC-12 | 员工可对正常状态的物资发起申领 |
