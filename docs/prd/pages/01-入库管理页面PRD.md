## 1. 页面概述

| 项目 | 内容 |
|------|------|
| 页面名称 | 入库管理 |
| 访问角色 | 库管人员、系统管理员 |
| 页面功能 | 管理入库单登记、执行入库操作、查看入库记录 |
| 核心价值 | 将采购到货的物资登记入库，实现库存自动增加 |

## 3. 功能流程

### 3.1 入库单列表展示流程

1. 库管进入入库管理页面
2. 系统加载入库单列表（默认按入库时间倒序）
3. 支持按入库单号搜索
4. 支持按物资名称搜索
5. 支持按日期范围筛选
6. 支持按物资ID筛选（从库存明细页跳转时）

### 3.2 新增进库流程

1. 库管点击「新建入库单」按钮
2. 系统弹出新建入库弹窗
3. 库管选择物资（下拉列表，显示物资名称和编码）
4. 库管输入入库数量（数字输入，最小值为1）
5. 库管输入入库单价（自动带出物资单价）
6. 库管选择入库时间（日期时间选择器，默认当前时间）
7. 库管填写备注（可选）
8. 库管点击「确认」按钮
9. 系统验证数据有效性
10. 系统创建入库单并增加库存
11. 系统关闭弹窗并刷新列表
12. 系统显示操作成功提示

### 3.3 编辑入库单流程

1. 库管点击「编辑」按钮
2. 系统弹出编辑入库弹窗（数据回填）
3. 库管修改入库信息
4. 库管点击「确认」按钮
5. 系统更新入库单
6. 系统关闭弹窗并刷新列表

### 3.4 查看入库单详情流程

1. 库管点击「查看」按钮
2. 系统弹出详情对话框
3. 显示入库单完整信息
4. 显示操作历史时间线

## 4. 界面元素清单

### 4.1 筛选区域

| 元素 | 类型 | 说明 |
|------|------|------|
| 入库单号输入框 | Input | 按入库单号模糊搜索 |
| 物资名称输入框 | Input | 按物资名称模糊搜索 |
| 入库时间选择器 | DateRangePicker | 日期范围选择，格式：YYYY-MM-DD |
| 查询按钮 | Primary Button | 触发筛选 |
| 重置按钮 | Default Button | 清空筛选条件 |

### 4.2 操作区域

| 元素 | 类型 | 说明 |
|------|------|------|
| 新建入库单按钮 | Primary Button | 打开新建入库单弹窗 |
| 刷新按钮 | Success Button | 刷新列表 |
| 返回物资列表按钮 | Info Button | 仅在按物资筛选时显示，返回库存明细页面 |

### 4.3 数据表格

| 元素 | 类型 | 说明 |
|------|------|------|
| 入库单号 | Table Column | 入库单号 |
| 物资编码 | Table Column | 物资编码 |
| 物资名称 | Table Column | 物资名称 |
| 入库数量 | Table Column | 入库数量 |
| 入库单价 | Table Column | 格式：¥xx.xx |
| 入库金额 | Table Column | 格式：¥xx.xx |
| 入库时间 | Table Column | 格式：YYYY-MM-DD HH:mm |
| 操作员 | Table Column | 操作人姓名，无数据显示"-" |
| 备注 | Table Column | 备注信息，无数据显示"-" |
| 操作 | Button Group | 编辑/查看按钮 |

### 4.4 新建/编辑入库单对话框

| 元素 | 类型 | 说明 |
|------|------|------|
| 弹窗标题 | Text | "新建入库单" 或 "编辑入库单" |
| 物资选择 | Select | 下拉列表，显示"名称 (编码)"，支持搜索过滤 |
| 入库数量 | NumberInput | 数字输入框，最小值为1 |
| 入库单价 | Input | 数字输入，单位：元，自动带出物资单价 |
| 入库时间 | DateTimePicker | 日期时间选择器 |
| 备注 | Textarea | 可选，填写入库备注 |
| 确认按钮 | Primary Button | 提交表单 |
| 取消按钮 | Default Button | 关闭弹窗 |

### 4.5 查看详情对话框

| 元素 | 类型 | 说明 |
|------|------|------|
| 弹窗标题 | Text | "入库单详情" |
| 入库单信息 | Descriptions | 入库单号、物资编码、物资名称、物资单位、入库数量、入库单价、入库金额、入库时间、操作员、备注 |
| 操作历史 | Timeline | 显示操作时间线 |

## 5. 交互细节

### 5.1 新增进库弹窗交互

| 交互 | 行为 |
|------|------|
| 选择物资 | 自动带出该物资的单价到入库单价字段 |
| 确认提交 | 校验通过后提交，显示loading状态 |
| 入库成功 | 关闭弹窗，显示成功toast，刷新列表 |
| 入库失败 | 显示错误toast，弹窗保持打开 |

### 5.2 编辑入库弹窗交互

| 交互 | 行为 |
|------|------|
| 点击编辑 | 数据回填到表单，物资不可更改 |
| 确认提交 | 校验通过后提交 |
| 更新成功 | 关闭弹窗，显示成功toast，刷新列表 |
