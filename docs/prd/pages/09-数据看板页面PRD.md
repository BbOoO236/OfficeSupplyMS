## 1. 页面概述

| 项目 | 内容 |
|------|------|
| 页面名称 | 数据看板（首页/仪表盘） |

## 3. 功能流程

### 3.1 管理员仪表盘加载流程

1. 用户登录后进入首页
2. 系统调用 `/dashboard/admin` 获取管理员仪表盘数据
3. 系统加载统计数据（今日申请、待审批、本月消耗、需补货物资）
4. 系统加载待审批申请列表
5. 系统加载快捷入口

### 3.2 员工仪表盘加载流程

1. 用户登录后进入首页
2. 系统调用 `/dashboard/employee` 获取员工仪表盘数据
3. 系统加载统计数据（今日申请、待审批）
4. 系统加载我的申领列表
5. 系统加载快捷入口

### 3.3 快捷入口流程

1. 用户点击快捷入口按钮
2. 系统跳转到对应页面

## 4. 界面元素清单

### 4.1 欢迎区域

| 元素 | 类型 | 说明 |
|------|------|------|
| 用户问候语 | Text | 早上好/下午好/晚上好 + 用户名 |
| 日期信息 | Text | 今天是 X年X月X日 星期X |
| 申请统计 | Text | 当前已完成 X 项物资申请 |
| 新建申请按钮 | Primary Button | 跳转至申领单创建页面 |

### 4.2 统计卡片区（管理员）

| 元素 | 类型 | 说明 |
|------|------|------|
| 今日申请卡片 | Stat Card | 今日提交的单申请数量 |
| 待审批卡片 | Stat Card | 待审批的申请数量 |
| 本月消耗卡片 | Stat Card | 本月消耗的物资数量 |
| 需补货物资卡片 | Stat Card | 需要补货的物资数量（红色主题当>0） |

### 4.3 统计卡片区（员工）

| 元素 | 类型 | 说明 |
|------|------|------|
| 今日申请卡片 | Stat Card | 今日提交的单申请数量 |
| 待审批卡片 | Stat Card | 待审批的申请数量 |

### 4.4 最近申请表格

| 元素 | 类型 | 说明 |
|------|------|------|
| 单号 | Table Column | 申领单号 |
| 物资名称 | Table Column | 物资名称 |
| 数量 | Table Column | 申领数量 |
| 时间 | Table Column | 申请时间 |

| 字段 | 类型 | 说明 |
|------|------|------|
| stats.todayApplications | Integer | 今日申请数量 |

| stats.completedApplications | Integer | 已完成申请数量 |

| 状态 | 说明 |
|------|------|

| OUTBOUND | 已出库 |
| CANCELLED | 已撤销 |
