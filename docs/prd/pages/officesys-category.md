## 1. 页面概述

### 1.1 页面目的

提供物资类别的管理功能，包括类别列表查看、新增类别、编辑类别信息、删除类别等操作。系统管理员可通过此页面对物资分类体系进行维护。

### 1.2 访问角色

| 角色 | 权限 |
|------|------|
| 系统管理员 | 增删改查全部类别 |
| 其他角色 | 无访问权限 |

### 1.3 入口

- 左侧菜单：基础数据 > 物资类别
- 仅系统管理员可见此菜单项

## 3. 功能流程

### 3.1 类别列表查询流程

```
1. 页面加载 → 自动请求类别列表
2. 返回数据 → 渲染表格
3. 用户输入筛选条件 → 点击查询
4. 返回筛选结果 → 更新表格
5. 点击重置 → 清空表单 → 重新加载全部数据
```

### 3.2 新增类别流程

```
1. 点击"新增类别"按钮
2. 弹出新增对话框
3. 填写表单：类别名称、类别描述
4. 点击确定 → 调用API: POST /api/categories
5. 成功 → 关闭对话框 → 刷新列表 → 提示成功
```

### 3.3 编辑类别流程

```
1. 点击表格"编辑"按钮
2. 弹出编辑对话框（数据回填）
3. 修改表单信息
4. 点击确定 → 调用API: PUT /api/categories/{id}
5. 成功 → 关闭对话框 → 刷新列表 → 提示成功
```

### 3.4 删除类别流程

```
1. 点击"删除"按钮
2. 弹出确认对话框
3. 点击确定 → 调用API: DELETE /api/categories/{id}
4. 成功 → 刷新列表 → 提示成功
```

## 5. 数据需求

### 5.1 API接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/categories | GET | 获取类别列表 |
| /api/categories | POST | 创建类别 |
| /api/categories/{id} | PUT | 更新类别信息 |
| /api/categories/{id} | DELETE | 删除类别 |

### 5.2 类别数据结构

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 类别ID |
| name | String | 类别名称 |
| description | String | 类别描述 |
| status | Integer | 状态：1=正常，0=禁用 |
| createTime | String | 创建时间 |
