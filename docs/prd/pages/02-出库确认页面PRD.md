## 3. 功能流程

### 3.1 出库单列表展示流程

1. 库管进入出库管理页面
2. 系统加载出库单列表（默认按出库时间倒序）
3. 支持按出库单号搜索
4. 支持按物资名称搜索
5. 支持按出库类型筛选（申领出库/调拨出库/损耗出库/其他出库）
6. 支持按日期范围筛选

### 3.2 新增出库流程

1. 库管点击「新建出库单」按钮
2. 系统弹出新建出库弹窗
3. 库管选择物资（下拉列表，显示物资名称和编码）
4. 库管选择出库类型
5. 库管输入出库数量（数字输入，最小值为1）
6. 如果是申领出库，选择关联的申领单
7. 库管填写备注（可选）
8. 库管点击「确认」按钮
9. 系统验证数据有效性
10. 系统创建出库单并扣减库存
11. 系统关闭弹窗并刷新列表
12. 系统显示操作成功提示

### 3.3 编辑出库单流程

1. 库管点击「编辑」按钮
2. 系统弹出编辑出库弹窗（数据回填）
3. 库管修改出库信息
4. 库管点击「确认」按钮
5. 系统更新出库单
6. 系统关闭弹窗并刷新列表

### 3.4 查看出库单详情流程

1. 库管点击「查看」按钮
2. 系统弹出详情对话框
3. 显示出库单完整信息
4. 显示操作历史时间线

## 4. 界面元素清单

### 4.1 筛选区域

| 元素 | 类型 | 说明 |
|------|------|------|
| 出库单号输入框 | Input | 按出库单号模糊搜索 |
| 物资名称输入框 | Input | 按物资名称模糊搜索 |
| 出库类型下拉框 | Select | 全部/申领出库/调拨出库/损耗出库/其他出库 |
| 出库时间选择器 | DateRangePicker | 日期范围选择，格式：YYYY-MM-DD |
| 查询按钮 | Primary Button | 触发筛选 |
| 重置按钮 | Default Button | 清空筛选条件 |

### 4.2 操作区域

| 元素 | 类型 | 说明 |
|------|------|------|
| 新建出库单按钮 | Primary Button | 打开新建出库单弹窗 |
| 刷新按钮 | Success Button | 刷新列表 |
| 返回物资列表按钮 | Info Button | 仅在按物资筛选时显示 |

### 4.3 数据表格

| 元素 | 类型 | 说明 |
|------|------|------|
| 出库单号 | Table Column | 出库单号 |
| 物资编码 | Table Column | 物资编码 |
| 物资名称 | Table Column | 物资名称 |
| 出库类型 | Table Column Tag | 申领出库(绿色)/调拨出库/损耗出库(红色)/其他出库 |
| 出库数量 | Table Column | 出库数量 |
| 出库时间 | Table Column | 格式：YYYY-MM-DD HH:mm |
| 操作员 | Table Column | 操作人姓名，无数据显示"-" |
| 备注 | Table Column | 备注信息，无数据显示"-" |
| 关联申领单 | Table Column | 关联的申领单号，无数据显示"-" |
| 操作 | Button Group | 编辑/查看按钮 |

### 4.4 新建/编辑出库单对话框

| 元素 | 类型 | 说明 |
|------|------|------|
| 弹窗标题 | Text | "新建出库单" 或 "编辑出库单" |
| 物资选择 | Select | 下拉列表，显示"名称 (编码)"，支持搜索过滤 |
| 出库类型 | Select | 申领出库/调拨出库/损耗出库/其他出库 |
| 出库数量 | NumberInput | 数字输入框，最小值为1 |
| 出库时间 | DateTimePicker | 日期时间选择器 |
| 备注 | Textarea | 可选，填写出库备注 |
| 关联申领单 | Select | 当类型为"申领出库"时显示 |
| 确认按钮 | Primary Button | 提交表单 |
| 取消按钮 | Default Button | 关闭弹窗 |

### 4.5 查看详情对话框

| 元素 | 类型 | 说明 |
|------|------|------|
| 弹窗标题 | Text | "出库单详情" |
| 出库单信息 | Descriptions | 出库单号、出库类型、物资编码、物资名称、物资单位、出库数量、出库时间、操作员、关联申领单、出库原因、备注 |
| 操作历史 | Timeline | 显示操作时间线 |

### 4.6 出库类型说明

| 类型值 | 显示文本 | 标签颜色 |
|--------|----------|----------|
| APPLICATION | 申领出库 | success(绿色) |
| TRANSFER | 调拨出库 | primary(蓝色) |
| LOSS | 损耗出库 | danger(红色) |
| OTHER | 其他出库 | warning(橙色) |

## 5. 交互细节

### 5.1 新增出库弹窗交互

| 交互 | 行为 |
|------|------|
| 物资搜索 | 输入关键字过滤下拉选项 |
| 类型切换 | 申领出库时显示关联申领单下拉框 |
| 确认提交 | 校验通过后提交，显示loading状态 |
| 出库成功 | 关闭弹窗，显示成功toast，刷新列表 |
| 出库失败 | 显示错误toast，弹窗保持打开 |
