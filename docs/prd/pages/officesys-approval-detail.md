## 1. 页面概述

### 1.1 功能定位

申领详情页面展示申领单的完整信息及审批历史，支持查看、编辑、审批、出库、撤销、回退等操作。

### 1.2 角色说明

| 角色 | 可用操作 |
|------|----------|
| 普通员工 | 查看详情、编辑(仅PENDING状态)、撤销(仅PENDING状态) |
| 系统管理员 | 查看详情、编辑(仅PENDING状态)、审批(仅PENDING状态)、出库(仅TO_BE_OUTBOUND状态)、回退状态 |

### 1.3 页面结构

```
+------------------------------------------------------------------+
|  顶部导航栏（Logo、系统名称、当前用户信息、退出按钮）              |
+------------------------------------------------------------------+
|  左侧菜单（256px固定宽度）  |  主内容区                           |
|  - 首页/仪表盘            |  +--------------------------------+ |
|  - 物资管理              |  |  面包屑：申领管理/申领记录 >    | |
|    - 物资列表            |  |  申领详情                       | |
|    - 库存明细            |  +--------------------------------+ |
|  - 申领管理              |  |  [库存不足警示框]               | |
|    - 我的申领            |  |  当前库存 < 申领数量时显示      | |
|  - 数据看板              |  +--------------------------------+ |
|  - 基础管理              |  |  申领信息卡片                   | |
|  - 系统管理              |  |  单号 / 申请人 / 部门 / 物资   | |
|                           |  |  数量 / 用途 / 当前库存 / 状态 | |
|                           |  +--------------------------------+ |
|                           |  |  审批历史时间线                 | |
|                           |  |  提交 > 审批通过 > 已出库       | |
|                           |  +--------------------------------+ |
|                           |  |  [操作按钮组]                   | |
+------------------------------------------------------------------+
```

## 2. 功能需求

### 2.1 库存不足警示

| 触发条件 | 当前库存 < 申领数量 |
|----------|---------------------|
| 样式 | el-alert警告提示框 |
| 标题 | 库存不足 或 库存已缺货 |
| 说明 | 当前库存数量小于申领数量时的提示 |
| 位置 | 页面顶部，优先于申领信息显示 |

### 2.2 申领信息展示

| 字段 | 说明 |
|------|------|
| 申领单号 | 系统生成的单号 |
| 申请人 | 提交该申领的员工姓名 |
| 所属部门 | 申请人所属部门 |
| 物资名称 | 申领的物资名称 |
| 物资编码 | 物资编码 |
| 申领数量 | 数量 + 单位 |
| 用途 | 员工填写的申领用途 |
| 当前库存 | 该物资当前库存 + 单位 |
| 状态 | 待审批/已拒绝/待出库/已出库/已撤销 |
| 备注 | 申领时的备注信息 |

### 2.3 审批历史时间线

| 节点 | 说明 |
|------|------|
| 提交申领 | 显示提交时间和提交人 |
| 审批通过/拒绝 | 审批人操作后显示 |
| 已出库 | 出库操作后显示 |
| 已撤销 | 撤销操作后显示 |

### 2.4 操作按钮（按角色和状态显示）

#### 2.4.1 普通员工操作

| 按钮 | 显示条件 | 行为 |
|------|----------|------|
| 编辑 | 仅PENDING状态 | 进入编辑模式 |
| 撤销 | 仅PENDING状态 | 撤销该申领单 |
| 返回列表 | 始终显示 | 返回申领记录列表 |

#### 2.4.2 系统管理员操作

| 按钮 | 显示条件 | 行为 |
|------|----------|------|
| 审批 | 仅PENDING状态 | 弹出审批对话框 |
| 出库 | 仅TO_BE_OUTBOUND状态 | 确认出库 |
| 回退状态 | 仅TO_BE_OUTBOUND或REJECTED状态 | 回退到待审批 |
| 返回列表 | 始终显示 | 返回申领管理列表 |

### 2.5 审批对话框

| 字段 | 说明 |
|------|------|
| 类型 | $prompt对话框 |
| 输入审批意见 | 审批通过时可填写意见 |
| 通过按钮 | 确认审批通过 |
| 拒绝按钮 | 切换到拒绝原因输入 |

### 2.6 拒绝原因输入

| 字段 | 说明 |
|------|------|
| 类型 | $prompt嵌套对话框 |
| 输入拒绝原因 | 必填项 |
| 确定按钮 | 确认拒绝 |
| 取消按钮 | 返回审批对话框 |

## 3. 数据需求

### 3.1 页面初始化数据加载

1. 从URL参数(/applications/{id})获取申领单ID
2. 调用API加载申领单详情

### 3.2 API接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/applications/{id} | GET | 获取申领单详情 |
| /api/applications/{id} | PUT | 更新申领单（编辑） |
| /api/applications/approve | PUT | 审批申领单 |
| /api/applications/{id}/cancel | PUT | 撤销申领单 |
| /api/applications/{id}/outbound | PUT | 出库操作 |
| /api/applications/{id}/rollback | PUT | 回退状态 |

### 3.3 审批请求数据结构

```json
{
  "applicationId": 1,
  "action": "APPROVE",  // 或 "REJECT"
  "approvalRemark": "审批意见"
}
```

### 3.4 回退请求参数

| 参数 | 类型 | 说明 |
|------|------|------|
| toStatus | string | 回退目标状态：PENDING |

## 4. 交互流程

### 4.1 查看详情流程

```
用户从列表页点击"查看"进入详情页
    ↓
页面加载申领单完整信息
    ↓
显示库存警示（如有）
    ↓
显示审批历史时间线
```

### 4.2 编辑流程

```
用户点击"编辑"按钮
    ↓
表单切换为编辑模式
    ↓
用户修改物资/数量/用途/备注
    ↓
点击"保存"提交更新
    ↓
刷新详情页显示新数据
```

### 4.3 审批流程

```
管理员点击"审批"按钮
    ↓
弹出审批对话框
    ↓
输入审批意见，点击"通过"或"拒绝"
    ↓
通过：状态变为TO_BE_OUTBOUND
拒绝：状态变为REJECTED
    ↓
刷新详情页
```

### 4.4 出库流程

```
管理员点击"出库"按钮
    ↓
弹出确认对话框
    ↓
确认后状态变为OUTBOUND
    ↓
刷新详情页
```

### 4.5 撤销流程

```
员工点击"撤销"按钮
    ↓
弹出确认对话框
    ↓
确认后状态变为CANCELLED
    ↓
刷新详情页
```

## 5. 异常处理

| 场景 | 处理方式 |
|------|----------|
| 申领ID不存在 | 显示错误提示，返回列表 |
| 加载详情失败 | 显示错误提示 |
| 审批操作失败 | 显示错误提示，留在详情页 |
| 出库操作失败 | 显示错误提示 |
| 撤销操作失败 | 显示错误提示 |

## 6. 验收标准

| 编号 | 标准描述 |
|------|----------|
| AC-1 | 库存不足时显示警示框 |
| AC-2 | 显示完整申领信息：单号、申请人、部门、物资、数量、用途、库存、状态、备注 |
| AC-3 | 审批历史时间线正确显示各节点 |
| AC-4 | 员工可编辑自己PENDING状态的申领单 |
| AC-5 | 员工可撤销自己PENDING状态的申领单 |
| AC-6 | 管理员可审批PENDING状态的申领单 |
| AC-7 | 管理员可对TO_BE_OUTBOUND状态执行出库 |
| AC-8 | 管理员可回退TO_BE_OUTBOUND/REJECTED状态到PENDING |
| AC-9 | 审批时支持通过或拒绝，拒绝需填原因 |
| AC-10 | 操作后正确更新状态并刷新页面 |
