## 1. 页面概述

### 1.1 功能定位

申领单创建页面是用户提交物资申领的核心页面，支持多物资选择、数量编辑、用途说明填写、紧急程度选择、期望领用时间设置，并提供提交前预览确认功能，确保申领信息准确无误。

## 2. 功能需求

### 2.1 已选物资区域

| 字段 | 要求 |
|------|------|
| 位置 | 页面顶部，作为独立卡片区域 |
| 展示内容 | 物资名称、规格、单价、申领数量（默认1）、小计金额、删除按钮 |
| 数量操作 | 支持手动输入数字，支持[-]/[+]按钮增减，最小为1 |
| 删除操作 | 点击"删除"按钮，弹出确认提示，确认后移除该物资 |
| 空状态 | 无已选物资时显示"请从下方添加物资"提示文字 |
| 小计金额 | 单价 x 申领数量，自动计算 |

### 2.2 物资搜索选择区

| 字段 | 要求 |
|------|------|
| 搜索框 | 输入物资名称关键字，支持模糊搜索 |
| 搜索按钮 | 点击后执行搜索 |
| 结果列表 | 显示搜索结果，每条显示：名称、规格、单价、当前库存 |
| 添加按钮 | 每条搜索结果右侧，点击后将物资添加到"已选物资区域" |
| 已有判断 | 已添加的物资在搜索结果中显示"已添加"状态，不可重复添加 |
| 空结果 | 搜索无结果时显示"未找到相关物资" |

### 2.3 用途说明

| 字段 | 要求 |
|------|------|
| 控件类型 | textarea多行文本框 |
| 字符限制 | 最多200字 |
| 必填校验 | 提交时校验是否填写 |

### 2.4 紧急程度

| 字段 | 要求 |
|------|------|
| 控件类型 | radio单选按钮组 |
| 选项 | 一般(NORMAL)、紧急(URGENT)、非常紧急(VERY_URGENT) |
| 默认值 | 一般(NORMAL) |
| 必填校验 | 提交时校验是否选择 |

### 2.5 期望领用时间

| 字段 | 要求 |
|------|------|
| 控件类型 | 日期时间选择器 |
| 日期范围 | 只能选择今天及以后的日期时间 |
| 格式 | yyyy-MM-dd HH:mm:ss |
| 必填校验 | 提交时校验是否选择 |

### 2.6 备注

| 字段 | 要求 |
|------|------|
| 控件类型 | textarea多行文本框 |
| 字符限制 | 最多200字 |
| 必填校验 | 非必填，可选 |

### 2.7 提交前预览确认

| 触发条件 | 用户点击"提交申领"按钮，且通过所有校验 |
|----------|----------------------------------------|
| 弹窗内容 | 显示申领预览：物资列表（名称、编码、数量、单位、小计）、紧急程度、期望领用时间、申领用途、备注 |
| 操作按钮 | "确认提交"（主按钮）、"返回修改"（默认按钮） |
| 确认提交 | 调用API分别为每个物资提交申领单 |
| 返回修改 | 关闭弹窗，返回表单继续编辑 |

## 3. 数据需求

### 3.1 页面初始化数据加载

1. 加载物资列表供选择（支持搜索）
2. 从URL参数（?materialId=xxx&materialName=xxx）获取预设物资ID和名称
3. 如果有预设物资，自动将该物资添加到已选列表（数量默认为1）
4. 支持编辑模式（URL包含:id参数），加载已有申领单数据进行编辑

### 3.2 API接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/materials | GET | 获取物资列表，支持分页和搜索 |
| /api/applications | POST | 提交申领单 |
| /api/applications/{id} | PUT | 更新申领单（编辑模式） |
| /api/applications/{id} | GET | 获取申领单详情（编辑模式） |

### 3.3 提交数据结构

```json
{
  "materialId": 1,
  "quantity": 2,
  "purpose": "部门日常办公使用",
  "urgency": "NORMAL",
  "expectedTime": "2026-04-25 10:00:00",
  "remark": "紧急需要"
}
```

**说明：** 每个物资单独提交一个申领单，支持多物资同时申领。

## 4. 交互流程

### 4.1 从物资管理页进入

```
用户在物资管理页点击"申领"按钮
    ↓
跳转至创建页，URL携带物资ID和物资名称参数
    ↓
页面自动添加该物资到已选列表
    ↓
用户补充用途说明、紧急程度、期望领用时间
    ↓
点击"提交申领" → 预览确认 → 提交
    ↓
跳转到"我的申领"页面
```

### 4.2 直接进入创建页

```
用户从左侧菜单进入发起申领页面
    ↓
页面无预设物资，显示空已选列表
    ↓
用户在搜索区搜索并添加物资
    ↓
填写用途说明、紧急程度、期望领用时间
    ↓
点击"提交申领" → 预览确认 → 提交
    ↓
跳转到"我的申领"页面
```

### 4.3 多物资申领流程

```
用户添加第一个物资
    ↓
用户点击"继续添加物资"返回选择界面
    ↓
用户搜索并选择第二个物资
    ↓
重复以上步骤添加更多物资
    ↓
填写统一的用途、紧急程度、期望时间
    ↓
预览并确认提交
    ↓
系统分别为每个物资创建独立的申领单
    ↓
跳转到"我的申领"页面
```

## 5. 异常处理

| 场景 | 处理方式 |
|------|----------|
| 搜索接口失败 | 显示Toast提示"搜索失败，请重试" |
| 提交接口失败 | 关闭预览弹窗，显示错误提示"提交失败，请重试" |
| 校验失败 | 高亮对应字段，显示错误提示文字 |
| 网络超时 | 显示Toast提示"网络异常，请重试" |
| 申领数量超过库存 | 提交时提示"物资[名称]库存不足，当前库存[xxx]" |

## 6. 验收标准

| 编号 | 标准描述 |
|------|----------|
| AC-1 | 已选物资区域支持添加、移除、修改数量操作 |
| AC-2 | 搜索区支持按名称或编码关键字搜索物资 |
| AC-3 | 已添加的物资不可重复添加，搜索结果中显示"已选"状态 |
| AC-4 | 用途说明为必填项，提交时校验 |
| AC-5 | 紧急程度支持一般/紧急/非常紧急三个选项，默认"一般" |
| AC-6 | 期望领用时间为必填项，选择今天及以后的日期时间 |
| AC-7 | 备注为可选项，不限制必填 |
| AC-8 | 点击"提交申领"弹出预览确认弹窗 |
| AC-9 | 预览弹窗显示完整申领信息（物资清单、紧急程度、期望时间、用途、备注），支持确认或返回修改 |
| AC-10 | 提交成功后分别创建每个物资的申领单，跳转到"我的申领"页面 |
| AC-11 | URL带有materialId参数时，自动添加该物资到已选列表 |
| AC-12 | 支持编辑模式，可加载并修改已有申领单 |
