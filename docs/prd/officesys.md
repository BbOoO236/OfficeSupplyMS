## 1. 系统概述

企业办公室物资管理系统是一款面向中小企业办公室物资申领管理的数字化平台，通过"线上申领审批 + 智能库存算法 + 数据可视化看板"三位一体的模式，实现物资管理从粗放式向精细化的转型升级。

### 1.1 核心价值

| 痛点 | 解决方案 | 效果 |
|------|----------|------|
| 手工登记效率低 | 线上数字化管理 | 申领周期从2-3天缩短至4小时内 |
| 审批流程繁琐 | 多级审批流 | 实时跟踪审批进度 |
| 库存数据滞后 | 实时库存更新 + 智能预警 | 账实一致率达95%以上 |
| 物资浪费难控 | ABC分类 + 异常检测 | 消耗透明化可追溯 |

### 1.2 目标用户

| 角色 | 核心职责 | 使用频率 |
|------|----------|----------|
| 普通员工 | 浏览物资目录、提交申领单、查看申领进度 | 日常 |
| 系统管理员 | 审批申领单、管理出入库、管理用户和物资、数据统计 | 每日 |

## 2. 技术架构说明

### 2.1 技术栈

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 前端框架 | Vue.js 3 + Element UI | 组件化开发，生态成熟 |
| 前端图表 | ECharts | 数据可视化 |

### 7.2 API接口规范

- 基础路径：`/api`
- 认证方式：JWT Token
- 请求格式：JSON
- 响应格式：`{ code, message, data }`

### 7.3 关键业务规则

1. **密码策略**：长度≥6位，首次登录强制修改
2. **账号锁定**：密码错误5次锁定15分钟
3. **审批流程**：管理员审批（员工提交 → 管理员审批 → 管理员确认出库）
4. **库存预警**：库存≤安全库存显示"库存紧张"，库存=0显示"已缺货"
5. **ABC分类**：每日凌晨定时计算，基于年消耗金额占比
