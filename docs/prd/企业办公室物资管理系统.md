## 1. 产品概述

### 1.1 产品定位

企业办公室物资管理系统是一款面向中小企业办公室物资申领管理的数字化平台，通过"线上申领审批 + 智能库存算法 + 数据可视化看板"三位一体的模式，解决传统手工操作效率低、审批流程烦琐、库存数据滞后、物资浪费难控等核心痛点，实现物资管理从粗放式向精细化的转型升级。

### 1.2 项目背景

当前，部分企业在办公室物资管理中仍依赖手工Excel台账和纸质审批，存在以下问题：

| 痛点 | 现状描述 |
|------|----------|
| 效率低下 | 手工登记、查找物资信息耗时较长，单次申领平均耗时超过30分钟 |
| 审批流程繁琐 | 纸质审批需要逐级签字，跨部门协调困难，平均审批周期2-3天 |
| 库存数据滞后 | Excel表格更新不及时，常出现物资已用完但未及时补货的情况 |
| 浪费难以监控 | 缺乏消耗数据分析，无法识别异常申领行为 |

本系统旨在通过数字化手段实现物资流转全过程的实时记录与动态预警，为企业采购预算编制与成本控制提供科学依据。

### 1.3 目标用户

| 角色 | 核心职责 | 使用频率 |
|------|----------|----------|
| 普通员工 | 浏览物资目录、提交申领单、查看申领进度 | 日常 |
| 系统管理员 | 审批申领单、管理出入库、管理用户和物资、数据统计 | 每日 |

### 1.4 核心目标

| 优先级 | 目标 | 指标 |
|--------|------|------|
| P0 | 申领审批效率提升 | 申领单审批周期从2-3天缩短至4小时内 |
| P0 | 库存数据准确性 | 账实一致率达95%以上 |
| P1 | 物资消耗透明化 | 部门/个人消耗数据可追溯，支持月度统计 |
| P1 | 智能预警能力 | 库存低于安全库存时自动预警，覆盖率达100% |
| P2 | 辅助决策支持 | 提供物资分类、需求预测等算法分析结果 |

### 1.5 产品边界

**V1.0 支持范围：**
- 单企业、单一法人单位组织架构
- 物资类别：办公用品、办公设备、日常消耗品等非核心消耗品
- 审批流程：管理员审批（员工提交 → 管理员审批 → 管理员确认出库）
- 数据时效：实时数据更新，预测基于近6个月历史数据

**V1.0 暂不支持：**
- 多租户/集团化部署
- 跨企业物资调拨
- 供应商管理和采购询价
- 移动端APP（仅支持PC浏览器）
- 离线操作能力

## 2. 术语定义

| 术语 | 英文缩写 | 定义 |
|------|----------|------|
| ABC分类 | ABC Classification | 基于物资年消耗金额占比进行的分类：A类占70-80%（重点管理）、B类占10-20%（中等管理）、C类占5-10%（简单管理） |
| 补货点 | Reorder Point | 触发物资补货的库存阈值，计算公式：(日均消耗量 × 采购提前期) × 安全系数 |
| 安全库存 | Safety Stock | 为防止需求波动和供应延迟而设置的最低库存量 |
| 采购提前期 | Lead Time | 从提交采购申请到物资到货的时间周期（单位：天） |
| 异常申领 | Abnormal Request | 申领数量超过该用户/部门历史平均单次申领量3倍标准差的申领行为 |
| 库存周转率 | Inventory Turnover | 一定时期内库存被更新的频率，计算公式：期间消耗总额 / 平均库存额 |
| 出库 | Outbound | 物资从仓库发出的操作，通常关联已审批通过的申领单 |
| 入库 | Inbound | 物资进入仓库的操作，通常由采购到货触发 |

## 3. 功能需求

### 3.1 功能架构

```
企业办公室物资管理系统
├── 1. 基础信息管理
│   ├── 1.1 用户管理（账号、密码、角色、部门）
│   ├── 1.2 部门管理（部门增删改查、上下级关系）
│   └── 1.3 物资档案管理（类别、规格、单价、采购提前期、安全库存参数）
├── 2. 物资申领流程
│   ├── 2.1 物资浏览与搜索
│   ├── 2.2 申领单创建（关联物资、数量、用途）
│   ├── 2.3 我的申请（历史申领记录、状态跟踪）
│   ├── 2.4 待办任务（待审批/待处理列表）
│   └── 2.5 审批流程（管理员审批 → 确认出库）
├── 3. 库存核心管理
│   ├── 3.1 入库管理（入库单登记、库存增加）
│   ├── 3.2 出库管理（关联审批通过的申领单，库存扣减）
│   ├── 3.3 库存盘点（生成盘点差异单）
│   └── 3.4 动态预警（低于安全库存自动标红提醒）
├── 4. 智能算法分析
│   ├── 4.1 物资ABC分类
│   ├── 4.2 需求预测（周/月消耗量预测）
│   ├── 4.3 异常申领检测
│   └── 4.4 补货点计算
└── 5. 数据可视化与报表
    ├── 5.1 库存周转率看板
    ├── 5.2 部门消耗排行榜
    ├── 5.3 物资分类占比图（饼图）
    └── 5.4 预测与实际消耗对比图（折线图）
```

### 3.2 Epic 设计

#### Epic 1：用户与权限管理

| 字段 | 内容 |
|------|------|
| Epic编号 | Epic 1 |
| Epic名称 | 用户与权限管理 |
| Epic目标 | 实现基于角色的访问控制，确保不同角色只能操作对应权限范围内的功能 |
| 核心场景 | 1. 管理员创建员工账号并分配角色；2. 员工登录系统查看个人可操作功能；3. 管理员处理待办审批任务 |
| User Story列表 | User Story 1.1、1.2、1.3 |
| 功能边界 | 不支持单点登录(SSO)、不支持 LDAP 集成 |

**User Story 1.1**
```
● As a 系统管理员
● I want 创建员工账号并分配角色（员工/主管/库管/管理员）
● So that 员工能够登录系统并按角色获取对应功能权限
● 验收标准 (AC)：
1. 管理员可在用户管理页面新增用户，填写工号、姓名、部门、角色
2. 密码初始为随机6位数字，首次登录后强制修改
3. 用户列表展示账号状态（正常/禁用），支持禁用已离职员工账号
4. 同一员工只有一个有效账号
```

**User Story 1.2**
```
● As a 普通员工
● I want 使用工号和密码登录系统
● So that 能够访问系统并使用个人权限范围内的功能
● 验收标准 (AC)：
1. 登录页面显示工号、密码输入框及登录按钮
2. 密码错误超过5次自动锁定账号15分钟
3. 登录成功后显示系统首页（物资浏览/我的申请/我的待办）
4. 顶部导航栏显示当前登录人姓名和角色
```

**User Story 1.3**
```
● As a 系统管理员
● I want 管理组织部门架构
● So that 能够适应企业实际的部门设置
● 验收标准 (AC)：
1. 支持新增、编辑、删除部门
2. 部门支持上下级关系（最多3级）
3. 删除部门时需确认该部门下无在职员工
4. 部门列表以树形结构展示
```

#### Epic 5：智能算法分析

| 字段 | 内容 |
|------|------|
| Epic编号 | Epic 5 |
| Epic名称 | 智能算法分析 |
| Epic目标 | 通过算法辅助决策，实现物资精细化管理 |
| 核心场景 | 1. 系统自动计算物资ABC分类；2. 系统预测下月消耗量；3. 系统检测异常申领；4. 系统计算补货点 |
| User Story列表 | User Story 5.1、5.2、5.3、5.4 |
| 功能边界 | 不支持自定义算法参数、不支持算法模型训练 |

**User Story 5.1 - 物资ABC分类**
```
● As a 系统
● I want 根据物资年消耗金额自动计算ABC分类
● So that 帮助库管重点管理高价值物资
● 验收标准 (AC)：
1. 后台定时任务每日凌晨执行分类计算
2. 计算方法：按（单价 × 年消耗量）降序排列，计算累计金额占比
   - A类：累计占比 70%-80%
   - B类：累计占比 80%-90%（即中间 10%-20%）
   - C类：累计占比 90%-100%（即最后 5%-10%）
3. 每种物资有且只有一个分类标签
4. 分类结果在物资详情页显示
5. 库管可手动调整分类标签，并记录调整原因
```

**User Story 5.2 - 需求预测**
```
● As a 系统管理员
● I want 查看物资需求预测结果
● So that 指导采购计划制定
● 验收标准 (AC)：
1. 支持按物资查看近6个月的消耗量趋势
2. 简单移动平均：取近3个月消耗量均值作为下月预测值
3. 加权移动平均：近月权重0.5、上月0.3、再上月0.2
4. 预测结果展示为折线图
5. 库管可选择预测方法（简单平均/加权平均）
```

**User Story 5.3 - 异常申领检测**
```
● As a 系统
● I want 在申领提交时检测异常申领
● So that 防止物资浪费和滥用
● 验收标准 (AC)：
1. 申领单提交时，计算该用户/部门对该物资的历史平均单次申领量和标准差
2. 如果本次申领数量 > 平均值 + 3倍标准差，标记为"高风险"
3. 高风险申领单在前端显示红色警示
4. 高风险申领单在审批列表中特殊标记
5. 审批人可选择通过或驳回，驳回时建议填写原因
```

**User Story 5.4 - 补货点计算**
```
● As a 系统
● I want 动态计算每种物资的补货点
● So that 实现精准补货预警
● 验收标准 (AC)：
1. 后台定时任务每日凌晨执行补货点计算
2. 计算公式：补货点 = (日均消耗量 × 采购提前期) × 安全系数
3. 安全系数默认1.5，库管可调整
4. 日均消耗量 = 近30天消耗总量 / 30（排除零消耗日）
5. 计算结果在物资详情页显示
```

```

                           主管审批（通过/驳回）

```

```
库管创建入库单 → 选择物资和数量 → 确认入库 → 库存增加
```

**预警触发流程：**
```
定时任务计算补货点 → 库存 ≤ 补货点 → 标记为"库存紧张" → 首页预警卡片显示
```

### 9.3 关键公式

**ABC分类计算：**
```
1. 计算每种物资年消耗金额 = 单价 × 年消耗量
2. 按消耗金额降序排列
3. 计算累计金额和累计百分比
4. A类：累计百分比在70%-80%区间
   B类：累计百分比在80%-90%区间
   C类：累计百分比在90%-100%区间
```

**需求预测（简单移动平均）：**
```
预测值 = (上月消耗量 + 上上月消耗量 + 再上月消耗量) / 3
```

**需求预测（加权移动平均）：**
```
预测值 = 本月消耗量 × 0.5 + 上月消耗量 × 0.3 + 上上月消耗量 × 0.2
```

**补货点计算：**
```
补货点 = (日均消耗量 × 采购提前期天数) × 安全系数
日均消耗量 = 近30天消耗总量 / 30（排除零消耗日）
安全系数默认值 = 1.5
```

**异常申领检测：**
```
判断条件：申领数量 > 历史平均单次申领量 + 3 × 标准差
是 → 标记为高风险申领
```

**库存周转率：**
```
周转率 = 近30天消耗总额 / 平均库存额
平均库存额 = (期初库存 + 期末库存) / 2
```
